# Заметки по FinRL

## Что это

Первый открытый фреймворк финансового deep reinforcement learning (AI4Finance, MIT, 17k звёзд).
Три слоя: среды (`finrl/meta`) → агенты (`finrl/agents`, поверх SB3/ElegantRL/RLlib) → приложения (`finrl/applications`).
Пайплайн train-test-trade.

## Статус проекта

Репозиторий сам себя отчасти списал: README перенаправляет в **FinRL-X / FinRL-Trading**
как в актуальную, production-oriented архитектуру. Оригинал — образовательный research-прототип.

| | FinRL (Stage 1.0) | FinRL-X (Stage 3.0) |
|---|---|---|
| Парадигма | Deep RL | AI-Native (ML + DRL + LLM-ready) |
| Архитектура | монолит из трёх слоёв | полностью развязанные модули |
| Бэктест | свои циклы | движок `bt` |
| Лайв-трейдинг | базовый Alpaca | мультиаккаунт + риск-контроль |
| Конфиг | `config.py` | type-safe Pydantic + `.env` |

## Что полезно взять (и взято)

1. **Среда как объект.** state → action → reward → state. Наш `src/env.py` реализует это с честной
   бухгалтерией: `equity = cash + position * price`, комиссия taker + проскальзывание.
2. **Turbulence index.** Отклонение текущего шага доходности от среднего, нормированное на волатильность.
   Важная тонкость: тренд сам по себе turbulence не даёт — высокая turbulence означает разворот/шум.
   Шкала нормирована по 99-му перцентилю истории: порог 0.5 ≈ «худшие 20% наблюдений».
3. **Просадка как отдельный триггер.** После обвала turbulence может упасть (рынок «успокоился»),
   но убыток уже накоплен — поэтому риск режется и по drawdown от максимума > 15%.
4. **Штраф за oversized.** Превышение max_position_pct даёт отрицательный reward.
5. **Бейзлайны.** buy&hold и MVO. Вердикт «стратегия не обгоняет бейзлайны» — честная проверка.

## Что НЕ стоит брать

- **Обучение DRL-агентов.** Нужны тысячи сделок в истории, GPU, месяцы данных по DOW-30. При 4 сделках
  в журнале это бессмысленно — агент переобучится на шум.
- **Готовые среды из `finrl/meta`** как источник формулировки награды: там штраф за волатильность и оборот,
  то есть противоположность нашей задаче (не слить счёт).

## Проверенные результаты

`src/env.py`:
- растущий рынок, шорт: −8.27% (просадка 8.27%)
- падающий рынок, шорт: +8.40%
- растущий рынок, лонг: +5.46%
- V-образный разворот, шорт: −8.68% (просадка 18.18%)

`src/regime.py`:
- тренд: turbulence 0.0 → размер не меняется
- боковая волатильность: turbulence 0.605 → размер урезан вдвое
- обвал с боковиком: drawdown 30% → размер урезан вдвое
- восстановление после обвала: drawdown 0.33% → размер не меняется
