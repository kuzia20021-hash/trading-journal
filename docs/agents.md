# Роли агентов

Перенесены из TradingAgents и упрощены: без внешних LLM-ключей, аналитика выполняется мной в чате,
по данным Walt (цены, фандинг, объём) и веб-поиска.

## Аналитическая команда (работает параллельно)

1. **Технический аналитик** — тренд, моментум, уровни, ATR, дистанция до стопа.
2. **Новостной аналитик** — события, макро, отраслевые новости по инструменту.
3. **Сентимент-аналитик** — настроения, страх/жадность, объёмы и фандинг как прокси.
4. **Фундаментальный аналитик** — для акций: отчётность, оценка, red flags.

## Исследовательская команда

- Бык: аргументы за лонг / за шорт снижение.
- Медведь: контраргументы.
- Итог: один тезис на сделку, записанный в журнал ДО входа.

## Риск-менеджмент

- Риск на сделку в R (по умолчанию 1% капитала).
- Размер = min(риск-бюджет/стоп-расстояние, ограничение по марже и плечу).
- Стоп обязателен всегда. Ликвидация должна быть дальше стопа.
- Если риск сделки > 2% капитала — сделка не открывается.

## Портфельный менеджер

Одобряет или отклоняет сделку. Отклоняет, если нет стопа, если R к цели < 1.5,
или если вход нарушает правило «не более 2 сделок в одну зону волатильности».
